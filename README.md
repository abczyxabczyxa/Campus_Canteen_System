# Campus Canteen Ordering System

本项目面向校园环境构建了一个在线点餐平台，实现了从食堂与窗口管理到菜品展示、用户下单及订单评价的完整业务流程。系统采用 Django 作为后端框架，结合 MySQL 数据库进行数据存储，满足多角色、多场景的点餐需求。

## 一、功能总览

系统整体包含两个核心使用端：管理端与用户端，各自承担不同的业务功能。

1. 管理端功能（管理员 / 经营者）

    管理端用于维护平台中涉及的运营数据，包括：

    食堂基础信息的增删改查（名称、照片、卫生等级、开放状态）；

    各食堂窗口（档口）管理，包括经营者绑定、窗口描述、状态控制；

    菜品的管理（上架、下架、价格调整、详情修改、图片更新等）；

    控制窗口与食堂是否处于开放状态；

    查看窗口经营状况与订单记录，辅助日常管理。

2. 用户端功能（学生用户）

    用户端为学生提供在线点餐服务，主要功能包括：

    账号注册、登录、修改资料；

    查看食堂与窗口列表；

    浏览各窗口菜品，并可通过关键字搜索；

    添加菜品到购物车，生成订单；

    查看订单详情与历史订单；

    对订单中的菜品进行评价；

    管理收货地址（宿舍、楼栋等信息）。

## 二、项目结构说明

项目基于 Django 标准结构组织，代码按模块划分，便于维护和扩展：
```
project_root
 ├── canteen/          # 食堂与窗口相关逻辑
 ├── customer/         # 用户注册、登录、地址等
 ├── dish/             # 菜品、订单、评价模块
 ├── django_CCOS/      # 项目配置文件
 ├── media/            # 图片上传文件夹
 ├── static/           # CSS、JS、静态资源
 └── templates/        # 页面模板
```

## 三、运行步骤

以下步骤说明如何在本地环境部署运行系统。

```cmd
安装依赖
pip install -r requirements.txt
```

1. 配置数据库

    在数据库中创建项目所需的库：

    ```sql
    create database django_CCOS;
    ```

    然后在项目配置文件中填写数据库连接信息。

2. 执行数据库迁移

    ```python
    python manage.py makemigrations
    python manage.py migrate
    ```

3. 启动服务

    ```python
    python manage.py runserver
    ```

    后台入口地址为 /admin，用户端从根路径进入主页。

## 四、数据库设计概述

系统的核心数据表结构通过 Django ORM 定义并生成，主要模型包括：

- Canteen：食堂实体，管理卫生等级、开放状态等属性；

- Shop：窗口实体，绑定所属食堂与经营者；

- ShopManager：窗口经营者账号，含联系方式与在线状态；

- Customer：用户实体，含昵称、电话、地址等；

- Address：用户地址信息；

- Dish：菜品实体，包括价格、描述、图片与售卖状态；

- Orders：订单记录，包含下单时间、订单状态、价格等；

- Comments：评价记录，包含评分与评价内容。

表之间通过外键构建关联关系，支持完整的点餐流程。
